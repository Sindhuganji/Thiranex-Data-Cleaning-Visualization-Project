# Data-Cleaning-Visualization-Project

A Data Cleaning and Visualization project using Python, Pandas, Matplotlib, and Seaborn to analyze and visualize cafe sales data. This project focuses on preprocessing raw data, handling inconsistencies, and generating meaningful business insights through visual analytics.

⸻

Project Overview

This project works on a raw cafe sales dataset containing:

* Missing values
* Invalid entries
* Duplicates
* Mixed data types
* Inconsistent records

The dataset is cleaned, processed, and visualized to uncover trends, patterns, and business insights.

Data Cleaning Steps

The following preprocessing techniques were applied:

1. Handling Missing Values

* Filled missing numerical values
* Filled missing categorical values

2. Removing Invalid Entries

Replaced:

* ERROR
* UNKNOWN

with null values for proper cleaning.

3. Data Type Conversion

Converted numerical columns into proper numeric format.

4. Duplicate Removal

Removed duplicate records from the dataset.

5. Date Processing

Converted transaction dates into datetime format for trend analysis.
