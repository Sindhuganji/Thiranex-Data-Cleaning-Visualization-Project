# Data Cleaning & Visualization Project

A Python-based Data Cleaning and Visualization project focused on processing raw cafe sales data to identify inconsistencies, handle missing values, and generate meaningful insights through data visualization techniques.

---

## Project Overview

This project works on a messy cafe sales dataset containing:
- Missing values
- Invalid entries
- Duplicate records
- Mixed data types

The dataset is cleaned, processed, and visualized to uncover trends, patterns, and business insights using Python data analysis libraries.

---

## Features

- Data Cleaning & Preprocessing
- Handling Missing Values
- Removing Duplicates
- Data Type Conversion
- Outlier Detection
- Statistical Summaries
- Data Visualization
- Trend Analysis
- Business Insight Generation

## Objectives of the Project

- Clean and preprocess raw data
- Handle missing and inconsistent values
- Convert incorrect data types
- Visualize important trends and patterns
- Generate business insights using visual analytics

---

## Data Cleaning Steps

### 1. Handling Missing Values
- Filled missing numerical values
- Filled missing categorical values

### 2. Removing Invalid Entries
Replaced invalid entries such as:
- ERROR
- UNKNOWN

with null values for proper processing.

### 3. Data Type Conversion
Converted numerical columns into proper numeric format.

### 4. Duplicate Removal
Removed duplicate records from the dataset.

### 5. Date Processing
Converted transaction dates into datetime format.

---

## Visualizations Included

### 1. Most Sold Items
Bar chart showing top-selling products.

### 2. Revenue by Item
Displays revenue generated by each item.

### 3. Payment Method Distribution
Pie chart representing customer payment preferences.

### 4. Correlation Heatmap
Shows relationships between numerical features.

### 5. Daily Sales Trend
Line graph showing sales patterns over time.

### 6. Outlier Detection
Boxplots used for identifying outliers in sales data.
